# Casos de Uso

## Ator Principal

Jogador

## Casos de Uso

### Selecionar Personagem

Descrição:
Permite ao jogador escolher um personagem
para iniciar a partida.

---

### Responder Pergunta

Descrição:
Permite ao jogador responder perguntas
apresentadas pelo sistema.

---

### Utilizar Item

Descrição:
Permite utilizar itens especiais durante a batalha.

---

### Visualizar Ranking

Descrição:
Permite consultar a pontuação dos jogadores.

---

### Encerrar Partida

Descrição:
Finaliza a partida quando um dos personagens
atinge 0 pontos de vida.
