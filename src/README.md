# Pasta src

Esta pasta contém os arquivos de implementação (.cpp) do projeto.

Os arquivos .cpp armazenam a implementação dos métodos declarados nos arquivos de cabeçalho presentes na pasta include.

Arquivos presentes:

* character.cpp → Implementação da classe Character.
* warrior.cpp → Implementação do comportamento do Guerreiro.
* mage.cpp → Implementação do comportamento do Mago.
* archer.cpp → Implementação do comportamento do Arqueiro.
* boss.cpp → Implementação do comportamento do chefe.
* item.cpp → Implementação da classe Item.
* healthpotion.cpp → Implementação da Poção de Vida.
* attackbuff.cpp → Implementação do Elixir de Ataque.
* questionmanager.cpp → Implementação do gerenciamento de perguntas.
* mainwindow.cpp → Implementação da lógica da interface gráfica.
* main.cpp → Ponto de entrada da aplicação.

Esta separação entre declarações (.h) e implementações (.cpp) segue uma prática comum em projetos desenvolvidos em C++.
