# Pasta include

Esta pasta contém os arquivos de cabeçalho (.h) do projeto.

Os arquivos .h armazenam as declarações das classes, incluindo:

* Atributos
* Métodos
* Relacionamentos de herança
* Interfaces públicas

Arquivos presentes:

* character.h → Classe base abstrata para todos os personagens.
* warrior.h → Classe derivada que representa o Guerreiro.
* mage.h → Classe derivada que representa o Mago.
* archer.h → Classe derivada que representa o Arqueiro.
* boss.h → Classe derivada que representa o chefe da partida.
* item.h → Classe base abstrata para os itens.
* healthpotion.h → Item responsável pela recuperação de vida.
* attackbuff.h → Item responsável pelo aumento de ataque.
* questionmanager.h → Gerencia o banco de perguntas do jogo.
* mainwindow.h → Declaração da janela principal da aplicação.

Os arquivos desta pasta representam a estrutura das classes utilizadas pelo sistema.
